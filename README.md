# Michael Zirkin - Personal Website

My personal portfolio site, built with plain HTML and CSS and hosted on GitHub Pages.

Live site: https://mishkazk.github.io

## Files
- `index.html` - the site
- `style.css` - styles

## Local development
Open `index.html` in a browser, or run a small server:

```
python3 -m http.server 8000
```

Then visit http://localhost:8000
